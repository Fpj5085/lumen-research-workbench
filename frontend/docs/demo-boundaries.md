# 模拟边界与来源声明

## 常驻声明

页面顶部常驻「合成数据 · 模拟执行」。所有阶段推进、耗时与回执由浏览器内纯 TypeScript
状态机生成，不代表 Python 服务、定时任务、消息队列或真实行情源。

## 明确不做

- 不调用任何后端接口；`src` 与 `dist` 中不存在指向外部主机的请求代码。
- 不使用 `localStorage` / `sessionStorage` / `indexedDB`；刷新即回到初始演示状态。
- 不加载远程字体、图片、脚本或样式；字体使用本地系统字体栈。
- 不提供登录、真实账户、下单或支付能力。
- 不包含真实股票代码、真实公司名称或真实行情；标的统一使用 `DEMO001`–`DEMO024`。
- 不复用任何外部发布批次编号或批次日期：快照 ID 为自有的 `demo-snapshot-NNN`，
  示例日期取自虚构 2030 年日历，页面常驻声明「非实际交易日」。
- 不含任何私有研究公式、评分规则、阈值或策略命名；`displayScore` 是可复现的合成派生量，
  只用于演示排序。

## 数据来源

| 内容 | 来源 |
| --- | --- |
| 24 个标的的名称、行业、趋势 | 本项目构造的固定词表 |
| 每个标的 180 根 OHLCV | `src/simulation/generator.ts`，固定 seed 180 |
| 交易日历 | 只跳过周末的合成日历 |
| 榜单、观察、持仓、历史快照 | 由上述合成数据在浏览器内派生 |
| 图表 | 原创内联 SVG（`src/components/`） |
| 图标 | 原创 SVG（`public/favicon.svg`、`BrandMark`） |

## 可复现性

生成器为纯函数：相同 seed 与相同标的定义必然产生完全相同的序列。
`digestOf()` 提供规范化摘要，单元测试断言「两次生成摘要一致」与「不同 seed 改变数据」。

## 与私有项目的边界

本目录在独立位置从零创建，未复制任何私有仓库的代码、数据、规则、截图、日志或 Git 历史；
私有项目仅作为「高层概念背景」，其规模数字、运行状态与证据路径均未进入本演示。
